# Sorting Algorithm Visualizer and Performance Analyzer

A browser-based sorting visualization implemented with plain HTML, CSS, and JavaScript.

## Project files

- `Sorting Algorithm Visualizer and Performance Analyzer/index.html` — page entry point.
- `style.css` — visual styling.
- `script.js` — client-side interaction and sorting logic.

## Run

Open `index.html` directly in a modern browser. There is no package manager, server, build step, or environment configuration in this repository.
